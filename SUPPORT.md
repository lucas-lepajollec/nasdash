# Support

Start with the [README](README.md) and the [documentation](https://docs.nasdash.lucas-homelab.fr). Deployment-specific help is available in [access control](ACCESS_CONTROL.md), [backup and restore](BACKUP_AND_RESTORE.md), and [integration troubleshooting](docs/INTEGRATIONS_TROUBLESHOOTING.md).

## Ask for help

Search existing [GitHub issues](https://github.com/lucas-lepajollec/nasdash/issues) first. If the problem is reproducible and not already reported, open a bug report with the NasDash version or commit, deployment method, sanitized configuration details, reproduction steps and relevant logs.

Remove tokens, passwords, cookies, private addresses, hostnames, topology details and persistent `data/` contents before posting. General setup questions may be closed if the documentation already answers them or the environment cannot be reproduced.

Suspected vulnerabilities must follow [SECURITY.md](SECURITY.md) and must not be disclosed in a public issue.
